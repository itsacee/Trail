Google Calendar setup
  1. Google Cloud → enable Google Calendar API
  2. Create a service account → download JSON key
  3. Share nubulah.fr4@gmail.com calendar with that service account email (Make changes to events)
  4. In Vercel env: GOOGLE_SERVICE_ACCOUNT_JSON = the JSON key (one line), and optional GOOGLE_CALENDAR_ID=nubulah.fr4@gmail.com
  5. Keep your Apple Calendar subscribed to the iCal link above — both can run together
